## Website Overview
This is a multi-page responsive web project for the university event **TechSpark Fest 2026**.

### Pages Included:
- **Home (`index.html` / `Main.html`):** Event hero banner, student information, flexbox poster previews, registration steps & upcoming events, JavaScript interactive note box, and enquiry links.
- **Gallery (`gallery.html`):** Interactive flexbox gallery showcasing all four event posters (`music.png`, `campfire.png`, `dance.png`, `hack.png`).
- **Events Schedule (`tables.html`):** Complete timetable of events, timings, venues, and faculty coordinators with hover styling.
- **Registrations (`form.html`):** Clean event registration form with validation and styled input fields.

## Features Implemented
- **HTML5 Semantic Structure:** `<header>`, `<nav>`, `<section>`, `<aside>`, `<footer>`, `<main>`, `<table>`, `<form>`.
- **CSS3 & Flexbox Layout:** Responsive navigation bar, card grid layouts, and multi-column desktop-to-mobile layouts.
- **Responsive Web Design:** Media queries (`@media (max-width: 768px)`) ensuring smooth scaling on phones and desktops.
- **Interactive JavaScript:** Dynamic background & border color toggle for event announcements (`changeNoteColor()`).
- **GitHub Pages Ready:** Configured with `index.html` and `.nojekyll` for fast, seamless static hosting.
